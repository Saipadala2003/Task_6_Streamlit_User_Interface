## Objective
To develop a user-friendly Streamlit web interface for interacting
with a trained deep learning model and displaying handwritten digit
predictions.

## Technologies Used
- Python
- Streamlit
- TensorFlow
- Keras
- NumPy
- Pillow
- MNIST Dataset
- CNN

## Application Features
- Upload handwritten digit images
- Convert images to grayscale
- Resize images to 28 × 28 pixels
- Normalize pixel values
- Predict the handwritten digit
- Display prediction confidence
- Display prediction probabilities

## Dataset

MNIST Handwritten Digit Dataset:
https://www.tensorflow.org/datasets/catalog/mnist

The MNIST dataset contains 28 × 28 grayscale images of handwritten
digits from 0 to 9 and is used for handwritten digit classification.

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py

The application will open in the browser at:

http://localhost:8501

## Expected Result

The application accepts a handwritten digit image and displays:
- Predicted Digit
- Prediction Confidence
- Prediction Probability Chart
